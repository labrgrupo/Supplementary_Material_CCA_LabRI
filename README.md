## Overview

<img src="www/Logo.svg" width="350px" height="250px" align="right" alt="LabRI logo" />

This repository provides the supplementary research materials supporting the **LabRI** study associated with *Clinica Chimica Acta*. It brings together the datasets, analytical scripts, and study reports used to evaluate reference interval estimation across real-world and simulated data.

**LabRI (Laboratory Reference Interval)** is a data-source-agnostic, multi-method statistical consensus framework implemented in R/Shiny. Its estimation workflow combines preprocessing, cluster-driven truncation, complementary reference-limit estimators, consensus rules, and statistical uncertainty assessment.

The study compares **LabRI, Truncated Minimum Chi-square (TMC), Truncated Maximum Likelihood (TML), refineR, and reflimR** using the **PRIDe-RL** comparison framework.

> **Repository scope**  
> This is the study's supplementary material repository. Source code for the LabRI and PRIDe-RL applications is maintained in the separate repositories listed under [Related software](#related-software).

The materials described in the manuscript comprise the following components:

## Study datasets

### Group 1 · Real-world data

Group 1 comprises **12 analytes** from published studies in which reference intervals were established using directly selected reference individuals. The reference intervals reported in those publications were adopted as the **comparative references (CRs)**.

| Original study | Analytes evaluated | Source |
| :--- | :--- | :--- |
| **Omuse et al., 2020 — Kenya** | Lactate dehydrogenase (**LDH**), total calcium (**Ca**), amylase (**AMY**), free thyroxine (**FT4**), and thyroid-stimulating hormone (**TSH**). | [Original publication](https://doi.org/10.1371/journal.pone.0235234) |
| **Abbam et al., 2021 — Ghana** | Alanine aminotransferase (**ALT**), gamma-glutamyl transferase (**GGT**), hemoglobin (**Hb**), absolute lymphocyte count (**LYM**), platelet count (**PLT**), red blood cell count (**RBC**), and white blood cell count (**WBC**). | [Original publication](https://doi.org/10.1371/journal.pone.0245585) |

### Group 2 · Simulated data

Group 2 uses three simulated datasets distributed with the `refineR` package. Each scenario was assessed at **five sample sizes**, including its full available size, yielding **15 scenario–sample-size conditions**.

| Scenario | Full dataset size | Non-pathological / pathological composition | Evaluated sample sizes (*n*) |
| :--- | ---: | :---: | :--- |
| **`testcase1`** | 10,000 | 80% / 20% | 500 · 1,000 · 2,000 · 5,000 · 10,000 |
| **`testcase2`** | 50,000 | 60% / 40% | 500 · 1,000 · 5,000 · 10,000 · 50,000 |
| **`testcase4`** | 100,000 | 90% / 10% | 500 · 1,000 · 5,000 · 10,000 · 100,000 |

The reference interval documented for each simulated non-pathological population was adopted as its CR. Subsamples were drawn using **DataSampleR** with a fixed random seed.

These scenarios are subsamples of the package datasets; they should be distinguished from independently generated simulations for each sample size.

## Comparative performance assessment

The **Performance Ranking by Index of Deviation of Reference Limits (PRIDe-RL)** framework evaluates the difference between each estimated reference limit and its CR, expressed in units of the corresponding **permissible difference (pD)**.

In this study, equivalence intervals were defined using a standard-normal coverage factor of **1.645**, corresponding to approximately **90% central coverage**. A reference limit is conforming when its absolute deviation index is **≤ 1**.

| Dimension | What it measures |
| :--- | :--- |
| **Conformity — d1** | Proportion of reference limits within their respective equivalence intervals. |
| **Proximity — d2** | Overall closeness to the comparative reference, based on mean absolute deviation indices. |
| **Tail behavior — d3** | Larger deviations, summarized by the 90th percentile of the absolute deviation indices. |
| **Severity — d4** | Frequency of deviations exceeding twice the permissible difference. |

The **PRIDe-RL score** prioritizes the number of conforming limits and uses the geometric mean of d2–d4 as a secondary component. A heatmap complements the numerical assessment by displaying the direction and magnitude of deviations across methods and evaluation conditions.

Statistical uncertainty was assessed separately using the ratio of each reference limit's **90% confidence interval width** to the **central 95% reference interval width** (*W*CI/*W*RI).

## Reproducing the study

### Study environment

| Software | Version used in the study |
| :--- | :--- |
| **R** | 4.6.1 |
| **RStudio** | 2026.09.0+174 |

### Suggested workflow

1. **Obtain the supplementary materials.** Download this repository using **Code → Download ZIP**, or clone it with Git:

   ```bash
   git clone https://github.com/labrgrupo/Supplementary_Material_CCA_LabRI.git
   ```

2. **Select the dataset group.** Use the supplied real-world data or the simulated testcase and sample-size condition of interest. Preserve the measurement units and comparative reference limits used in the study.
3. **Reproduce subsampling when needed.** Open `DataSampleR.Rmd` in RStudio and retain the fixed seed and sampling settings supplied with the study materials. The same random seed requires the same input data and sampling procedure to reproduce a subsample.
4. **Inspect the original reports.** Use the comparator PDF reports and LabRI HTML reports to trace the estimates reported in the manuscript.
5. **Run the associated software for reanalysis.** Follow the installation and execution instructions in the [application repositories](#related-software). Match the study's inputs and analytical settings when comparing results.

> **Version tracking**  
> When reusing these materials, record the repository commit, application versions, package versions, input datasets, random seed, and analytical settings. Later software updates may produce results that differ from the archived study reports.

| Tool | Local execution | Web deployment |

## Data provenance and reuse

The study used previously published, publicly available, and simulated datasets. No new biological samples were collected, no intervention involving human participants was performed, and no identifiable individual-level information was accessed.

When reusing the real-world datasets, cite the original data publications as well as the LabRI study. When reusing the simulated scenarios, acknowledge the `refineR` package. Consult the applicable licensing and attribution terms for each source dataset and software component.
